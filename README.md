# IPL Cricket Data Analytics Using Python

## Project Overview
This project analyzes sample IPL cricket data using Python to understand player and team performance across the 2024 and 2025 seasons.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Project Activities
1. Created a cricket dataset using Pandas.
2. Calculated player strike rates.
3. Identified top run scorers.
4. Analyzed team-wise total runs.
5. Performed player ranking.
6. Analyzed match results.
7. Compared season-wise runs.
8. Created data visualization charts.
9. Exported the final report into CSV format.

## Visualizations
- Player Total Runs
- Team Wins
- Player Strike Rate
- Season Runs Comparison

## Project Files
- Python source code
- Project PDF
- CSV analysis report
- Visualization charts

## Learning Outcomes
Practical experience in Python programming, data manipulation, data analysis and visualization.

## Note
This project uses a manually created sample dataset and is not an official IPL statistical dataset.
